## 📊 Dataset

**Source:** [Agriculture Crop Production in India — Kaggle](https://www.kaggle.com/datasets/srinivas1/agricuture-crops-production-in-india)

| Column | Description |
|---|---|
| `Crop` | Name of the crop |
| `Crop_Year` | Year of cultivation (1997–2020) |
| `Season` | Kharif / Rabi / Whole Year / Autumn / Winter / Summer |
| `State` | Indian state |
| `Area` | Cultivated area (hectares) |
| `Production` | Total production (metric tons) |
| `Annual_Rainfall` | Annual rainfall (mm) |
| `Fertilizer` | Total fertilizer used (kg) |
| `Pesticide` | Total pesticide used (kg) |
| `Yield` | **Target** — production per unit area |

## 🗺️ Pipeline Overview

```
Raw CSV
  │
  ▼
[NB 01] Data Loading & EDA
  │  • Understand distributions, correlations, seasonal/state trends
  │
  ▼
[NB 02] Preprocessing & Feature Engineering
  │  • Handle missing values & outliers
  │  • Engineer: Fertilizer/Ha, Pesticide/Ha, Rainfall category, log transforms
  │  • Label encode categoricals
  │  • 70/15/15 train/val/test split
  │  • RobustScaler
  │
  ▼
[NB 03] Baseline Models
  │  • Linear Regression, Ridge, Lasso, ElasticNet
  │  • Decision Tree, KNN, SVR
  │  • Compare R², RMSE, MAE
  │
  ▼
[NB 04] Advanced Ensemble Models
  │  • Random Forest, Extra Trees, Gradient Boosting
  │  • XGBoost, LightGBM, CatBoost
  │  • Feature importance analysis
  │
  ▼
[NB 05] Hyperparameter Tuning
  │  • RandomizedSearchCV (Random Forest + XGBoost)
  │  • Optuna Bayesian optimization (optional)
  │  • 5-Fold Cross-Validation
  │
  ▼
[NB 06] Final Evaluation & Interpretability
  │  • Test-set metrics: R², RMSE, MAE, MAPE
  │  • Residual diagnostics, Q-Q plot
  │  • Error analysis by crop / state / season
  │  • SHAP feature importance & waterfall plots
  │
  ▼
[NB 07] Prediction Pipeline
     • CropYieldPredictor class
     • Single & batch predictions
     • Sensitivity analysis (fertilizer, rainfall)
     • Export reusable .pkl predictor
```

## ⚙️ Setup & Installation

### 1. Clone / Download this project

Place the downloaded Kaggle CSV `crop_production.csv`

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows
```

### 3. Install dependencies

**Core (required):**
```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy joblib
```

**Boosting libraries (strongly recommended):**
```bash
pip install xgboost lightgbm catboost
```

**Interpretability (optional but recommended):**
```bash
pip install shap
```

**Bayesian optimization (optional):**
```bash
pip install optuna
```

### 4. Launch Jupyter

```bash
pip install jupyter
jupyter notebook
```

## 🔮 Making Predictions

After running all notebooks, use the saved predictor:

```python
import joblib

predictor = joblib.load('models/crop_yield_predictor.pkl')

yield_pred = predictor.predict(
    crop           = 'Rice',
    crop_year      = 2020,
    season         = 'Kharif',
    state          = 'Punjab',
    area           = 150000,        # hectares
    production     = 600000,        # metric tons
    annual_rainfall = 950,          # mm
    fertilizer     = 75000000,      # kg
    pesticide      = 150000         # kg
)

print(f'Predicted Yield: {yield_pred:.4f} metric tons / hectare')
```

**Batch prediction from CSV:**

```python
import pandas as pd

df = pd.read_csv('my_new_data.csv')
df['Predicted_Yield'] = predictor.predict_batch(df)
df.to_csv('predictions.csv', index=False)
```

## 🧪 Feature Engineering Details

| New Feature | Formula |
|---|---|
| `Fertilizer_Per_Ha` | `Fertilizer / Area` |
| `Pesticide_Per_Ha` | `Pesticide / Area` |
| `Production_Per_Rainfall` | `Production / Annual_Rainfall` |
| `Rainfall_Category` | Binned into 5 bands (Very Low → Very High) |
| `Decade` | `(Crop_Year // 10) * 10` |
| `log_*` | `log1p` of Area, Production, Fertilizer, Pesticide, and per-ha variants |
